# Local-Build CPU Results

`main/` contains one complete experiment with eight configurations, raw samples, summaries, correctness records, plots and input hashes. Additional groups are retained exactly as produced by the original variability rule.

`build_provenance.json` records the compiler, original source-file hashes, compilation commands and locally built executable hashes. `environment_summary.json`, `status.json` and `power_snapshot.json` record the runtime environment and validation. `comparison.csv` contains 16 matched group-0 comparisons with Member 1's retained results.
