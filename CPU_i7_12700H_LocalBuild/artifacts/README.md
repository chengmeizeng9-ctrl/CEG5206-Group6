# Locally Compiled Release Artifacts

The benchmark, test executable, export executable and static library were compiled locally using GCC 12.5.0, Release (`-O3 -DNDEBUG`). These are not Member 1's precompiled executables. Checksums and compiler commands are recorded in `../results/build_provenance.json`.

Clean Release and Debug ASan/UBSan builds were also validated; only the measured Release artifacts are retained here.
