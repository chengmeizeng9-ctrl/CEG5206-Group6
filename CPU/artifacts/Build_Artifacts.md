# Compiled CPU Artifacts

This directory contains the compiled benchmark, export, and test executables and the static library from the recorded Release, clean-build, and sanitizer builds. The binaries were built on the recorded openEuler x86_64 environment; they may require a compatible Linux system and runtime libraries. Rebuild from the source with the commands in the CPU README when using another platform or toolchain.

CMake caches, generated Makefiles, and compile databases are omitted because they contain machine-specific paths and can be regenerated.
